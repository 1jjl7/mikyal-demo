# مكيال: طلبية الطازج بالتقويم السعودي

نموذج أولي لهاكاثون الفقد والهدر الغذائي (التحدي 04). يقترح لمدير قسم الطازج أو الشيف **كم يطلب أو يخبز من كل صنف بكرة**، ومع كل رقم **سبب مفهوم**.

- `engine/`: المحرك (Python): المحاكاة، التوصيات، الاختبار العكسي.
- `web/`: الواجهة (صفحة ثابتة، تُنشر على GitHub Pages).

> ⚠️ البيانات هنا **محاكاة** مبنية على 3 زيارات ميدانية: تثبت أن الحساب يشتغل، ولا تثبت أثرًا حقيقيًا.

```bash
cd engine
pip install -r requirements.txt
python make_sim.py && python mikyal.py && python backtest.py --tradeoff && python export_web.py
```
