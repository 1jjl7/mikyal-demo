# Mikyal (مكيال) – demo

Live: https://1jjl7.github.io/mikyal-demo/

Demo page for the Food Loss & Waste Hackathon (Qassim University, 22–23 Oct 2026), team أثر.
It shows tomorrow's suggested order per fresh item with a written reason, plus a backtest.
All numbers come from **simulated data** built on our field visits, not real store data.
